# Recorded Prime Agent harness

`physim_prime_agent` is the adapter used for the recorded BF case study with
Verifiers 0.3.1 and Prime Agent 0.9.5. The [reproduction guide](https://github.com/swpo/physim/blob/main/environments/physim/PRIME_AGENT.md)
and [experiment record](https://github.com/swpo/physim/blob/main/BF_CASE_STUDY.md)
live with the published study. They include image construction, provider
settings, and campaign diagnostics.

The task's experimental and prediction interfaces are independent of this
harness. The standard Bash harness remains available.
